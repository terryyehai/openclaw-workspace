1.　遊戲測試工具頁面
====================

**QA1 測試環境網址：**https://gp001-qa1-simulation.xwautc.online/index

1.1　登入參數說明
-----------------

  **欄位名稱**     說明 / 預設值
  ---------------- ------------------------------------------------
  **Agent**        下拉式選單，預設：「Jmeter總控台 (Jmeter)」
  **Sub Agent**    下拉式選單，預設：「PHP (披索 PHP)」
  **Account**      帳號輸入欄位，預設：PHP123456789
  **Game ID**      下拉式選單，選擇要測試的遊戲編號，預設：230001
  **Language**     下拉式選單，選擇遊戲語言，預設：English (en)
  **Login 按鈕**   完成以上設定後，點擊此按鈕進入遊戲頁面

2.　登入流程與 Loading Bar
==========================

點擊 Login 按鈕後，系統會顯示 Loading Bar 進度條，完成後透過
**window.open** 開啟新分頁進入遊戲。

4.3　玩家操作區
---------------

玩家用來控制遊戲流程的所有按鈕，包含 SPIN、BET 調整、Auto Play
及即停功能。

  ![image10.jpg](media/image10.jpg "image10.jpg"){width="0.5208333333333334in" height="0.5104166666666666in"}   **SPIN 按鈕**　在 Credit 足夠一把 BET 時，點擊後盤面開始滾動。
  ------------------------------------------------------------------------------------------------------------- -----------------------------------------------------------------------------------------------------
  ![image11.jpg](media/image11.jpg "image11.jpg"){width="0.4375in" height="0.4583333333333333in"}               **BET + 按鈕**　調整 BET 往上一階。無 Loop 型式，有封頂上限。搭配 SPIN 可觀察 Credit 扣除是否正確。
  ![image12.jpg](media/image12.jpg "image12.jpg"){width="0.4375in" height="0.4479166666666667in"}               **BET − 按鈕**　調整 BET 往下一階。無 Loop 型式，有最小值。搭配 SPIN 可觀察 Credit 扣除是否正確。
  ![image13.jpg](media/image13.jpg "image13.jpg"){width="0.4166666666666667in" height="0.4270833333333333in"}   **Auto Play 啟動**　Credit 足夠時，自動連續執行 SPIN。點擊後圖示切換為「Auto Play 停止」圖示。
  ![image14.jpg](media/image14.jpg "image14.jpg"){width="0.4583333333333333in" height="0.4895833333333333in"}   **Auto Play 停止**　自動播放進行中的停止按鈕，點擊後結束 Auto Play。
  ![image15.jpg](media/image15.jpg "image15.jpg"){width="0.4375in" height="0.4479166666666667in"}               **即停按鈕**　點擊後 SPIN 滾停速度加快，圖示同時切換為「取消即停」。
  ![image16.jpg](media/image16.jpg "image16.jpg"){width="0.4479166666666667in" height="0.4583333333333333in"}   **取消即停按鈕**　點擊後 SPIN 恢復正常滾停速度，圖示切換回「即停」。

5.　活動功能收納區（VP Logo 選單）
==================================

點擊左上角 VP Logo
活動功能按鈕，可展開或收合活動選單。選單依功能性質分為 USER 區塊與
FUNCTION 區塊。

*⚠
注意：活動功能區分常駐活動與特定時間開放的活動，實際顯示項目可能因時間不同而有所差異。*

5.1　USER 區塊
--------------

  ![image17.jpg](media/image17.jpg "image17.jpg"){width="0.4166666666666667in" height="0.4791666666666667in"}   **VP Logo 活動展開按鈕**　點擊後展開活動選單；再次點擊收合，主畫面恢復正常。
  ------------------------------------------------------------------------------------------------------------- --------------------------------------------------------------------------------------------------------
  ![image18.jpg](media/image18.jpg "image18.jpg"){width="0.4791666666666667in" height="0.5208333333333334in"}   **BAG（背包）**　玩家背包頁面，放置各式資源。內含四個頁籤：THIS GAME / OTHER GAME / ITEMS / MESSAGES。
  ![image19.jpg](media/image19.jpg "image19.jpg"){width="0.4479166666666667in" height="0.46875in"}              **INBOX（信件）**　玩家收件箱頁面，顯示系統或活動寄送的信件。
  ![image20.jpg](media/image20.jpg "image20.jpg"){width="0.4270833333333333in" height="0.4895833333333333in"}   **NEWS（公告）**　顯示遊戲最新消息與公告（ANNOUNCEMENT）。
  ![image21.jpg](media/image21.jpg "image21.jpg"){width="0.4479166666666667in" height="0.4791666666666667in"}   **USER（會員）**　玩家個人資訊頁面，內含三個頁籤：USER / VIP / HONOR WALL。

6.　設定選單
============

點擊右下角齒輪圖示，開啟底部設定選單列。選單列包含六個功能按鈕。

  -------------------------------------------------------------------------------------------------- ----------------------------------------------------------------------
  ![image29.jpg](media/image29.jpg "image29.jpg"){width="0.4166666666666667in" height="0.40625in"}   **齒輪（設定）按鈕**　位於遊戲畫面右下角，點擊後展開底部設定選單列。
  -------------------------------------------------------------------------------------------------- ----------------------------------------------------------------------

6.1　設定選單預覽
-----------------

![image30.jpg](media/image30.jpg "image30.jpg"){width="4.583333333333333in"
height="0.6770833333333334in"}

*▲ 設定選單列（由左至右：SOUND / NOTIFY / INFO / AUTO / RECORD /
CLOSE）*

6.2　設定功能說明
-----------------

  **功能**     說明
  ------------ -------------------------------------------
  **SOUND**    SOUND 開關按鈕，控制遊戲音效的開啟與關閉
  **NOTIFY**   NOTIFY 開關按鈕，控制遊戲通知的開啟與關閉
  **INFO**     開啟遊戲規則與玩法說明頁面
  **AUTO**     開啟自動玩（AUTOPLAY）功能設定頁面
  **RECORD**   開啟玩家遊戲記錄查詢頁面
  **CLOSE**    關閉設定選單列，返回主遊戲控制欄位
