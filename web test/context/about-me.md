# 專業身份 (Who We Are)
我們是推動產品品質與開發效率的**軟體品保工程師團隊 (QA Team)**。
我們不只是找 Bug 的防守者，更是從需求分析到產品交付的品質守門員。我們結合手動探索測試與自動化腳本，並積極導入 AI 輔助工具（如 AI-native IDEs）來優化測試流程。
- **核心職能**：自動化測試、測試策略規劃、QA SOP 制定、效能與安全性基礎驗證。

# 服務對象 (Who We Serve)
1. **開發團隊 (Developers)**：提供清晰、可重現的 Bug Report 與邊界條件 (Edge Cases) 分析，減少來回溝通成本。
2. **產品經理 (PM/PO)**：確保產品交付符合需求規格與驗收標準 (AC)，提供客觀的品質風險評估。
3. **終端用戶 (End-Users)**：攔截致命錯誤，確保流暢、穩定且符合直覺的使用者體驗。

# 目前重點 (Current Focus)
- **標準化測試流程**：持續優化並落實 QA SOP，確保團隊測試品質的一致性。
- **提升測試自動化比例**：針對核心功能 (Happy Path) 撰寫並維護可直接執行的自動化測試腳本。
- **AI 賦能品保**：探索並整合 AI 工具 (如 Vibe Coding 概念) 輔助測試案例生成與測試數據準備。
- **團隊賦能**：提升團隊整體技術視野與測試深度。
