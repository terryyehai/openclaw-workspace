點擊 FEATURE 1\~ FEATURE N 會進入遊戲特色演示流程

簡易流程 :

1.  在 DEMO MODE 進行多場 SPIN 搭配不同的 BET, 核對 Credit 變化是否正確

2.  FEATURE 1\~ FEATURE N, 全部執行完一輪, 點擊後滾輪會開始滾動,
    期間會有特色演示, 等待畫面完全靜止, 即可執行下一個 FEATURE

3.  執行設定功能驗證, 完成 SOUND / INFO / AUTO / CLOSE 這些功能操作

4.  完成上述流程後, 點擊 PLAY REAL, 確認遊戲頁面是否跳轉至正式遊戲頁面,
    畫面不再顯示 DEMO MODE
