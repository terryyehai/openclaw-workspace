## 遊戲自動化測試問題

### 問題描述
使用 Playwright/OpenClaw 自動化控制瀏覽器訪問遊戲網頁時，遊戲頁面呈現**全黑畫面**，無法正常顯示遊戲內容。

### 已嘗試的方案
1. ✅ 使用真實 Chrome (/usr/bin/google-chrome-stable)
2. ✅ 啟用硬體加速 (--enable-webgl, --use-gl=desktop)
3. ✅ 反檢測腳本 (隱藏 navigator.webdriver)
4. ✅ Chrome Remote Debugging + Selenium 連線 - **問題已解決！**

### 解決方案：Selenium + Chrome Remote Debugging
1. 先手動啟動 Chrome：`google-chrome-stable --remote-debugging-port=18800`
2. 使用 Selenium 連接：`options.add_experimental_option("debuggerAddress", "127.0.0.1:18800")`
