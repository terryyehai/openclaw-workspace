## 🎰 Slot Game 測試流程修正

- **問題**：測試截圖一直卡在登入頁面，沒有進入遊戲
- **發現**：頁面使用 `<select>` 下拉選單，不是 input 欄位
- **修復**：使用 `page.select_option()` 選擇：
  - Agent: `Jmeter` 或 `PHP`
  - 遊戲: `230001` (代碼如 230001, 230015)
  - 語言: `en`

## 🖥️ Gateway + TUI 問題

- **現象**：TUI 顯示離線
- **原因**：Gateway 設定 `auth.mode: "token"`，但 TUI 客戶端沒有提供 Token
- **錯誤日誌**：`reason=token_missing`, `authProvided=none`
- **修復**：將gateway `.auth.mode` 改為 `"none"`
- **驗證**：修改後 TUI 恢復正常連線
